# Бот-станок @VPNForge_bot

Онбординг-бот VPN-франшизы. Живёт на моём VPS. Даёт кнопку «Купить сервер», собирает доступы к
серверу нового узла (IP, root-пароль, токен его бота-продавца), затем **по SSH ставит на этот сервер
AmneziaWG** (обфусцированный WireGuard, не режется DPI) и отдаёт владельцу его бесплатный конфиг —
файлом, QR-кодом и текстом.

Контекст и план — во втором мозге: `obsidian/Бизнес планы/VPN-франшиза/00 - VPN Дашборд.md`.

## Запуск
```bash
npm install
cp .env.example .env      # впиши BOT_TOKEN (ENCRYPTION_KEY можно оставить пустым — сгенерится сам)
npm run typecheck
npm test                  # 11 тестов: валидация, крипто, парсинг
npm run dev
```

## Флоу бота
- **Шаг 1** (`/start`): «🛒 Купить сервер» (реф-ссылка), «📄 Подробная инструкция» (видео по file_id),
  «✅ Я купил сервер».
- **Шаг 2** («Я купил» → «⚙️ Настроить»): диалог онбординга с проверками (IP → root-пароль → токен),
  на каждом шаге — видео-подсказка, если задан `INSTR_*_VIDEO`. Креды шифруются AES-256-GCM (SQLite).
- **«🚀 Поднять VPN»**: станок по SSH ставит AmneziaWG (`scripts/install-amneziawg.sh`) и присылает
  конфиг файлом + QR + текстом для импорта в AmneziaVPN.

## Видео-инструкции
Пропиши свой id в `ADMIN_IDS`, запусти бота, пришли ему видео — он вернёт `file_id`. Вставь id в
`INSTR_BUY_VIDEO` / `INSTR_IP_VIDEO` / `INSTR_PASSWORD_VIDEO` / `INSTR_TOKEN_VIDEO`. Telegram раздаёт
видео сам, без перезагрузки с сервера.
