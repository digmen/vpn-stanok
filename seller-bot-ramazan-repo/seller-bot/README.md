# Бот-продавец (Фаза 3)

Ставится **на сервер узла** (станок деплоит его по SSH). Продаёт VPN конечным клиентам за
Telegram Stars, на оплату генерит нового клиента AmneziaWG локально и отдаёт конфиг (файл + QR + текст).
Владельцу (узлу) — бесплатный доступ. Кнопка «Заработай так же» ведёт в бота-станок (@VPNForge_bot) —
это замыкает реферальную петлю.

Контекст — во втором мозге: `obsidian/Бизнес планы/VPN-франшиза/00 - VPN Дашборд.md`.

## Запуск (на сервере узла)
```bash
npm install
cp .env.example .env      # SELLER_BOT_TOKEN (из @BotFather), OWNER_ID (твой Telegram id)
npm run typecheck
npm run start             # под pm2 в проде
```
Требует уже установленный AmneziaWG (его ставит станок, Фаза 2) и root-права.

## Как работает
- `/start` → «Купить VPN за N ⭐», «Заработай так же», и владельцу — «🆓 Мой VPN».
- Оплата: Telegram Stars (валюта `XTR`): invoice → pre_checkout → successful_payment.
- Выдача: `scripts/add-amneziawg-peer.sh` добавляет клиента (`--add-client`) → бот шлёт конфиг файл/QR/текст.
