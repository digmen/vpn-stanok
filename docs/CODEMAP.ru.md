# Карта кода

Что где лежит и за что отвечает. Описания взяты из комментариев в начале каждого файла. Обновлено 13.11.2026.

## Три процесса

| Процесс | Запуск | Что делает |
|---|---|---|
| **Станок** (`stanok-bot`) | `npm start` → `src/index.ts` | заводит узлы: покупка сервера, проверки, установка VPN по SSH, деплой продавца |
| **Поддержка** (`stanok-bot`) | `npm run support` → `src/support/main.ts` | бот техподдержки, отдельный процесс на **той же базе**, что станок |
| **Продавец** (`seller-bot`) | ставится станком на сервер каждого узла | продаёт VPN клиентам владельца: тарифы, оплата, выдача ключей, подписки |

## Станок — `stanok-bot/src/`

### Заведение узла

| Файл | Что делает |
|---|---|
| `index.ts` | точка входа, команды и роутинг |
| `onboarding.ts` | диалог сбора доступов с проверками; каждый шаг пишется в журнал ровно один раз |
| `host-guide.ts` | пошаговая покупка сервера |
| `terms.ts` | условия для владельцев ботов (в начале настройки и по `/terms`) |
| `preflight.ts` | проверка «есть ли куда стучаться» до того, как просить root-пароль |
| `tg-reach.ts` | достаёт ли сервер владельца до Telegram |
| `ru-probe.ts` | доступен ли узел из РФ (проба изнутри) |
| `relay.ts` | мультихоп-обход для узлов, недоступных из РФ напрямую |
| `protocols.ts` | выбор протокола при создании узла и при добавлении сервера |
| `provision.ts` | одна пара «скрипт установки + проверка, что реально работает» на протокол |
| `handshake-test.ts` | живая проверка «сервер принимает VPN», а не «скрипт не упал» |
| `ssh.ts` | удалённая установка по SSH |
| `deploy-seller.ts` | деплой продавца на сервер узла |
| `install-error.ts` | разбор упавшей установки VPN |
| `attach-location.ts` | новый сервер к существующему узлу (основной переустановлен, пароль в базе устарел) |
| `dns.ts` | работа с доменом узла |
| `bot-token.ts` | что делать, если владелец отозвал токен своего бота |
| `backup.ts` | хостер пересоздал VPS с новым IP — восстановление |

### Жизнь узлов и владельцев

| Файл | Что делает |
|---|---|
| `downtime.ts` | простой бота владельца: когда сообщать ему самому |
| `alert-state.ts` | тихие алерты: не шуметь повторами одного и того же |
| `nudges.ts` | напоминания тем, кто застрял на полпути |
| `broadcast.ts` | рассылка владельцам с возможностью отката |
| `revenue.ts` | сбор выручки узлов — основание для процента владельца станка |
| `analytics.ts` | сводка по людям: докуда дошёл, сколько раз ошибся, ушёл ли |
| `events.ts` | журнал шагов человека в боте |
| `chat-log.ts` | журнал диалога со станком в обе стороны |
| `setup-report.ts` | где владельцы спотыкаются, настраивая оплату картой |
| `channel.ts` | вход по подписке на канал владельца станка |
| `kv.ts` | мелкие настройки, которые админ меняет из чата без деплоя |
| `admin.ts` | алерты админам (`ADMIN_IDS`) |

### Основа

| Файл | Что делает |
|---|---|
| `db.ts` | SQLite и миграции (у владельца много узлов, но один бот-продавец) |
| `config.ts` | конфиг из env; ключ шифрования доступов (`.enckey`, если не задан) |
| `crypto-core.ts`, `crypto.ts` | AES-256-GCM для root-доступов узлов |
| `validate.ts` | чистые проверки ввода |
| `parse.ts` | достаёт клиентский конфиг из вывода установщика |
| `constants.ts` | инфраструктурные константы |

### Поддержка — `src/support/`

| Файл | Что делает |
|---|---|
| `main.ts` | запуск бота поддержки (@VPNForgeSupport_bot) |
| `bot.ts` | приём обращений, пересылка админам, ответы |
| `store.ts` | обращения и переписка — в той же базе, что у станка |
| `context.ts` | что станок знает о человеке — в карточку обращения, чтобы отвечать сразу по делу |

### Скрипты — `stanok-bot/scripts/`

Установщики протоколов на узел (`install-amneziawg.sh`, `install-vless-reality.sh`, `install-vless-ws-tls.sh`), сквозные проверки (`e2e.ts`, `harness-onboarding.ts`), отчёты (`report.ts`, `pull-events.ts`, `ru-audit.ts`), выкладка продавца (`push-seller.ts`) и лабораторные пробы обхода блокировок (`*-lab.sh`, `tiktok-*.sh`).

## Продавец — `seller-bot/src/`

| Файл | Что делает |
|---|---|
| `index.ts` | меню, оплаты, выдача; приложения по протоколам, которые реально есть у владельца |
| `locations.ts` | локации — VPN-серверы, с которых бот выдаёт ключи |
| `vpn.ts` | пара скриптов «выдать / отозвать» на протокол |
| `delivery.ts` | выдача ключа и приложение под каждый протокол |
| `subscription.ts`, `subscriptions.ts` | одна ссылка-подписка на клиента со всеми его ключами; кто купил и когда истекает |
| `settings.ts`, `price.ts` | тарифы, пробный период, приветствие — владелец задаёт сам |
| `trials.ts` | пробный период — один раз на человека |
| `promos.ts` | промокоды: скидка в процентах |
| `referrals.ts` | привёл друга — получил 30% его срока |
| `reminders.ts` | напоминание за N дней до конца подписки |
| `traffic.ts` | месячный лимит трафика на клиента |
| `tribute.ts` | оплата картой и СБП через Tribute рядом со звёздами Telegram |
| `stats.ts` | статистика владельцу |
| `campaigns.ts` | метки на ссылке (`?start=…`) для учёта кампаний |
| `ads.ts`, `promo-nudge.ts`, `branding.ts` | реклама франшизы клиентам — только с согласия владельца |
| `setup-log.ts` | журнал заминок владельца при настройке |
| `owner.ts`, `owner-config.ts` | кто владелец; конфиг владельца на локацию |
| `update.ts` | самообновление: бот сам проверяет и ставит новую версию |
| `ssh.ts` | тот же установщик, что у станка, для добавления локаций |
| `parse.ts`, `config.ts`, `constants.ts` | разбор вывода скриптов, конфиг, маркеры |

Скрипты продавца (`seller-bot/scripts/`): выдача и отзыв ключей на каждый протокол (`add-*-peer.sh`, `revoke-*-peer.sh`), учёт трафика, добавление локации, самообновление.
